Focus mode

Block distracting apps
Silence chosen apps during study sessions

Choose apps to block:

A web page can't actually block other apps on your phone — Android doesn't allow that. This switch stores your chosen apps and starts a study timer. Once you package this app with Capacitor and add a native plugin (using Android's UsageStatsManager or AccessibilityService), wire it up so calling code like window.NativeFocus.start(['com.example.app', 'com.another.app'], 25) blocks those apps for that many minutes. The app already calls this hook automatically whenever a timer starts with focus mode on.
